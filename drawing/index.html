Dibujo Libre Modular

Lienzo

Modo pincel P

Arrastra sobre el lienzo para pintar con la forma y el color activos. R rota la forma. Shift o click derecho para borrar.

Recolorear

Click o arrastra sobre las formas para aplicarles el color activo. Alt + click toma el color de una celda. Click derecho para borrar.

Seleccionar V

Arrastra sobre el lienzo para seleccionar un área. Ctrl/⌘ + A selecciona todo.

Arrastra la selección o usa las flechas para moverla (Shift = 5 celdas). Enter, Esc o click fuera para soltar. Supr para borrar.

Paleta

Click en un color para usarlo. + guarda el color activo. Click derecho quita un color.

Generar desde imagen reemplaza la paleta con los colores principales de una imagen (Ctrl+Z la recupera).

Celda seleccionada

Click en una celda para editarla

Dibujos

Guardar dibujo lo agrega a la lista. Click en una miniatura para seguir editándolo; Ctrl+Z vuelve a lo que tenías antes de abrirlo. × lo borra.
